# MIT Systems Programming Learning Path

The courses below are ordered from the foundations to more specialized topics. You do not need to complete every course: focus on the **Core path** first, then choose advanced topics that interest you.

## Priority 1 — Programming foundations

Start here if you are still getting comfortable with programming, C, or debugging.

1. [6.090 — Building Programming Experience](https://ocw.mit.edu/courses/6-090-building-programming-experience-a-lead-in-to-6-001-january-iap-2005/pages/syllabus/) — gentle programming preparation.
2. [6.087 — Practical Programming in C](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/) — a practical introduction to C.
3. [6.S096 — Introduction to C and C++ (2013)](https://ocw.mit.edu/courses/6-s096-introduction-to-c-and-c-january-iap-2013/) — another C/C++ introduction; use it for additional practice rather than taking every introductory course.
4. [6.S096 — Effective Programming in C and C++ (2014)](https://ocw.mit.edu/courses/6-s096-effective-programming-in-c-and-c-january-iap-2014/pages/syllabus/) — useful after you know basic C; covers more effective programming practices.
5. [6.005 — Software Construction](https://ocw.mit.edu/courses/6-005-software-construction-spring-2016/pages/syllabus/) — tests, design, and writing maintainable software; useful alongside later courses.

**Goal before moving on:** Be comfortable compiling and running small C programs, using pointers and arrays, reading compiler warnings, and debugging errors.

## Priority 2 — How computers execute programs

Learn how data and instructions are represented before studying operating systems.

1. [6.004 — Computation Structures (2017)](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/) — digital logic, processors, and the hardware/software boundary.
   - [Video playlist](https://learn.mit.edu/video-playlist/7859/mit-6-004-computation-structures-spring-2017)
   - [6.004 — Computation Structures (2009 syllabus)](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2009/pages/syllabus/) — an older alternative; the 2017 course is listed above as the primary choice.
2. [6.823 — Computer System Architecture](https://ocw.mit.edu/courses/6-823-computer-system-architecture-fall-2005/pages/syllabus/) — a deeper, more advanced architecture course; consider it after 6.004.

## Priority 3 — Core systems and operating systems

This is the central part of the systems-programming path.

1. [6.033 — Computer System Engineering](https://ocw.mit.edu/courses/6-033-computer-system-engineering-spring-2018/) — broad systems concepts and how components fit together.
2. [6.1810 — Operating System Engineering](https://pdos.csail.mit.edu/6.1810/2023/schedule.html) — hands-on operating-systems course using xv6. Make this a primary project-based course.
3. [6.828 — Operating System Engineering (2012)](https://ocw.mit.edu/courses/6-828-operating-system-engineering-fall-2012/pages/syllabus/) — an older version of the OS course; use as supplementary material, not a second required course.
4. [6.826 — Principles of Computer Systems](https://ocw.mit.edu/courses/6-826-principles-of-computer-systems-spring-2002/pages/syllabus/) — more advanced systems design and reasoning.

## Priority 4 — Performance, concurrency, and parallelism

Take these after you understand basic processes, memory, and operating-system concepts.

1. [6.172 — Performance Engineering of Software Systems](https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/pages/syllabus/) — measuring and improving performance.
2. [6.189 — Multicore Programming Primer](https://ocw.mit.edu/courses/6-189-multicore-programming-primer-january-iap-2007/) — introductory multicore and parallel programming.
3. [18.337J — Parallel Computing](https://ocw.mit.edu/courses/18-337j-parallel-computing-fall-2011/) — broader and more mathematical parallel-computing material.
4. [6.827 — Multithreaded Parallelism: Languages and Compilers](https://ocw.mit.edu/courses/6-827-multithreaded-parallelism-languages-and-compilers-fall-2002/pages/syllabus/) — advanced language and compiler topics.
5. [6.895 — Theory of Parallel Systems](https://ocw.mit.edu/courses/6-895-theory-of-parallel-systems-sma-5509-fall-2003/) — theoretical material; optional and advanced.

## Priority 5 — Choose a specialization

These are valuable, but are not prerequisites for learning core systems programming.

### Distributed systems

1. [6.824 — Distributed Computer Systems Engineering](https://ocw.mit.edu/courses/6-824-distributed-computer-systems-engineering-spring-2006/pages/syllabus/)
2. [6.852J — Distributed Algorithms](https://ocw.mit.edu/courses/6-852j-distributed-algorithms-fall-2009/pages/syllabus/) — more theory-heavy; take after an introductory distributed-systems course.

### Databases

1. [6.830 — Database Systems](https://ocw.mit.edu/courses/6-830-database-systems-fall-2010/)
2. [6.5830 — Database Systems assignments](https://dsg.csail.mit.edu/6.5830/assign.php) — a separate, newer course resource; useful for projects and exercises.

### Program analysis

- [6.820 — Fundamentals of Program Analysis](https://ocw.mit.edu/courses/6-820-fundamentals-of-program-analysis-fall-2015/pages/syllabus/) — advanced techniques for analyzing program behavior.

## Priority 6 — Further theory and algorithms

These are not needed for a first pass through systems programming. Return to them when a specific interest or project calls for them.

- [6.1200J — Mathematics for Computer Science](https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/pages/syllabus/) — discrete mathematics that supports algorithms and theory.
- [6.001 — Structure and Interpretation of Computer Programs](https://ocw.mit.edu/courses/6-001-structure-and-interpretation-of-computer-programs-spring-2005/pages/syllabus/) — a classic programming course, using Scheme rather than C.
- [6.080 — Great Ideas in Theoretical Computer Science](https://ocw.mit.edu/courses/6-080-great-ideas-in-theoretical-computer-science-spring-2008/pages/syllabus/)
- [18.404J — Theory of Computation](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/)
- [6.851 — Advanced Data Structures](https://ocw.mit.edu/courses/6-851-advanced-data-structures-spring-2012/pages/syllabus/)
- [6.854J — Advanced Algorithms (2008)](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/) — choose this or the 2005 version below, not both.
- [6.854J — Advanced Algorithms (2005)](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2005/pages/syllabus/)
- [6.895 — Essential Coding Theory](https://ocw.mit.edu/courses/6-895-essential-coding-theory-fall-2004/)
- [6.252J — Nonlinear Programming](https://ocw.mit.edu/courses/6-252j-nonlinear-programming-spring-2003/)
